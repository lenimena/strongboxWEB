# STRONGBOX HTML5 GD V2

Versión HTML5 sin backend.

## Cambios de esta versión
- Nueva pantalla principal tipo splash de videojuego.
- Fondo grande de bóveda creado como SVG local, sin servicios externos.
- Botón JUGAR grande y animado.
- Contador de ClicCoins.
- Indicador de nivel actual.
- Premios animados en la pantalla principal.
- Barra de características del juego.
- Mantiene el tablero 4x4, niveles, progreso local, animaciones y sonidos Web Audio de la versión anterior.

## Ejecutar
Abrir `index.html` en un navegador moderno.
